# 가정 및 한계

- GaonWorks Services는 가상회사다.
- 도입 전 구두/메신저 문의 250건은 시뮬레이션 baseline이다.
- 초기 1개월~3개월 성과도 운영 개선 시나리오를 설명하기 위한 시뮬레이션이다.
- 본 프로젝트는 특정 기업의 생산성 향상이나 ROI를 증명하지 않는다.
- 실제 회사에서는 SSO, RBAC, 감사로그, 개인정보 마스킹, 문서 보안등급, 실제 모델 단가가 추가되어야 한다.
- RAG 데모는 가상 사내 문서를 사용한다.
- 현재 직원용 데모는 실제 LLM API 호출을 생략하고 라우팅과 저장 흐름을 보여준다.
- 동료 재문의는 사용자 후속 피드백을 통해 수집한다고 가정한다.

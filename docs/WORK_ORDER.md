# 작업지시서 — 사내 AI 챗봇 운영 효율 개선 모니터링 시스템

## 목표
한 사람이 순서대로 개발한다. 데이터 정의를 먼저 고정하고, DB → 직원 챗봇 → 실시간 로그 → 분석 → 관리자 대시보드 → 문서/발표 순으로 작업한다.

## 작업 순서
1. 가상회사/기간/KPI 정의 고정
2. CSV 생성 및 SQLite 적재
3. 직원 챗봇 FAQ/RAG/LLM Router
4. 해결 여부/후속 행동 피드백 저장
5. 실시간 로그/주기 집계/이상치 알림
6. 7개 관리자 대시보드 탭
7. 테스트
8. README/발표/Q&A 최종 정리

## 완료 기준
- 초기 1개월 해결률 30.0%, 3개월차 45.1%가 데이터와 대시보드에서 일치
- 도입 전 월 문의 250건
- `response_wait_minutes` 정의가 질문자 관점의 대기시간으로 일치
- FAQ/RAG/LLM 지표를 분리
- Excel 중복 산출물 없음
- CSV와 SQLite만으로 재현 가능

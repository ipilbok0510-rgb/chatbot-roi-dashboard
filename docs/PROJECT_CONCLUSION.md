# 프로젝트 최종 결론

본 프로젝트의 시뮬레이션에서는 사내 챗봇 도입 초기 해결률을 30.0%로 설정했다. 이후 사용 기록을 모니터링하면서 반복 질문을 FAQ로 전환하고, 부족한 사내 문서를 RAG에 추가하며, Context와 Retry 정책을 조정한 결과 3개월차 해결률은 45.1%까지 증가하도록 구성했다.

같은 기간 재질문율은 38.0%에서 28.0%, 동료 재문의율은 44.0%에서 32.0%로 감소하고, FAQ/RAG 활용은 증가했다. 반면 3개월차에도 절반 이상의 요청이 챗봇만으로 해결되지 않으므로 "챗봇 도입이 이미 충분히 성공했다"고 결론 내리지 않는다.

최종 결론은 다음과 같다.

> 챗봇을 도입하고 사용 기록을 지속적으로 모니터링·관리하면서 도입 초기보다 일부 운영 효율이 개선되었다. 아직 운영 3개월이므로 효과는 비교적 작고 개선 여지가 크다. 장기적으로 대시보드에서 문제를 발견하고 FAQ·RAG·API·시스템을 개선한 뒤 같은 KPI를 재측정하는 과정을 반복하면 더 효율적인 사내 AI 서비스로 발전할 수 있다.

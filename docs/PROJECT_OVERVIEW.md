# 프로젝트 개요

## 목적
사내 AI 챗봇의 사용 기록을 모니터링하여 질문 해결 품질, FAQ/RAG/LLM 사용 방식, Token/API 효율, 오류 및 시스템 상태를 함께 확인하고 **문제 발견 → 원인 분석 → 개선 → 재측정**의 운영 사이클을 구현한다.

## 비교 시점
- 도입 전 baseline: 1개월, 직접 문의 250건
- 챗봇 초기: 1개월, 요청 600건, 해결률 30.0%
- 2개월차: 요청 720건, 해결률 37.1%
- 3개월차: 요청 850건, 해결률 45.1%

## 핵심 해석
사용량 증가가 성공을 의미하지 않는다. 해결률이 높아지고 재질문과 동료 재문의가 줄며, FAQ/RAG 비중이 높아지고 불필요한 LLM 호출과 Token이 줄어드는지를 함께 본다.
